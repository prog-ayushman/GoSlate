# 📝 GoSlate

**GoSlate** is a modern, minimalistic to-do list web app built with **React** and **Tailwind CSS**.  
Every day is a clean slate — organize your tasks, stay productive, and keep your goals in sight.

---

## 🌟 Features

- ✅ Simple and intuitive task management  
- 🕒 Add, delete, and mark tasks as completed  
- 🎨 Responsive and aesthetic UI built with Tailwind CSS  
- 🌙 Overlay welcome screen with blur effect and fade animation  
- ⚡ Lightweight and fast — built with React for smooth interactivity  
- 💾 Local storage support for persistent tasks  

---

## 🧠 Concept

> “Every day’s a clean slate.”

GoSlate provides a calm, distraction-free interface for managing your daily tasks.  
The goal is to combine *aesthetic simplicity* with *functional clarity* — productivity that feels effortless.

---

## 💻 Tech Stack

- **React** – for building dynamic UI and managing state  
- **Tailwind CSS** – utility-first styling for a clean, responsive design  
- **JavaScript (ES6+)** – task logic and interactivity
